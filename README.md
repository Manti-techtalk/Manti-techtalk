### Morabaraba AI Engine

**TypeScript · Game AI · Backend Architecture · Web Workers**

Built a game-playing AI system for **Morabaraba**, a traditional Basotho strategy game, capable of playing across three difficulty modes: **Easy, Medium, and Hard**.

* Developed the game-playing system and difficulty architecture for increasingly competitive play
* Built three playable AI modes — **Easy, Medium, and Hard** — now serving **100+ active users**
* Implemented advanced search techniques including **minimax, alpha-beta pruning, iterative deepening, Zobrist hashing, transposition tables, and move-ordering optimizations**
* Engineered the harder game modes for deeper decision-making while maintaining responsive gameplay
* Contribute to the **design, architecture, and implementation of the project's robust backend**, with a focus on reliability, scalability, maintainability, and clean service boundaries
* Integrated the AI engine into the production game experience and moved expensive computation off the main thread using **Web Workers**

[View project](https://morabaraba-vert.vercel.app)
